# Панель управления VPN

Самостоятельное React-приложение. Старые `admin/app.js` и `admin/app.css` удалены:
React владеет экранами, формами, таблицами, запросами, диалогами и навигацией.
Существующие защищённые `/admin/api/*` используются без изменений бизнес-правил.

## Компоненты

shadcn/ui New York / Radix из официального реестра
`https://ui.shadcn.com/r/styles/new-york/{component}.json`.
Это исходники компонентов, распространяемые самим shadcn/ui, а не HTML-имитация
их внешнего вида. Используются Button, Input, Textarea, Label, Table, Tabs, Select,
Checkbox, Switch, Sheet, Dialog, Command, DropdownMenu, Accordion, Card, Badge,
Alert, Separator, Skeleton, Progress и Sonner. Лицензия: `LICENSE.shadcn.md`.

Адаптации: русские подписи закрытия и поиска, ограниченная высота диалогов,
доступное имя/значение прогресса, фокусируемая область прокрутки таблиц.
Tailwind 4, палитра Zinc со скорректированным контрастом вторичного текста.

## Работа администратора

- **Обзор:** очередь обращений и выплат, быстрые действия; аналитика вынесена
  во вкладки. Переход из этапа воронки передаёт исходные границы когорты сервера.
- **Клиенты:** быстрые сегменты, поиск, дополнительные фильтры в боковой панели,
  активные фильтры с удалением по одному, карточки на телефоне. Профиль,
  платежи, устройства/HWID и переписка доступны из карточки клиента.
- **Финансы:** счета и история операций разделены. Stars не выдаются за рубли.
- **Акции:** собственный раздел, запуск сейчас или по МСК, явное предупреждение
  об уведомлении всех, статистика каждого запуска, повтор временных ошибок.
- **Рассылки:** аудитория → сообщение → проверка. API вызывается только после
  подтверждения. Шаблоны сохраняют свои аудитории, переменные и кнопки.
- **Настройки:** группы по задачам, только изменённые поля объединяются со свежим
  снимком сервера. Рефералка использует отдельный endpoint, без проверки чужих
  интеграций. Ошибка не стирает черновик; переход с изменениями требует решения.
- **Опасные операции:** отдельные меню, описание последствий, ввод подтверждения
  для удаления и восстановления. Массовое удаление всей когорты запрещено:
  backend не поддерживает её условия в `all_matching`; доступны выбранные строки.

## Сборка и проверки

```sh
cd admin-ui
npm ci
npm run check
npm run build
npm test
```

Нужен установленный Google Chrome. `npm test` запускает Playwright с моковыми API:
вход, все 14 разделов, ошибки и повтор сохранения, фильтры, защита черновиков,
отмена рассылки, создание промокода, подтверждение удаления, мобильная раскладка,
проверка доступности axe на ключевых экранах. Реальные сообщения не отправляются,
данные сервера не меняются. Скриншоты — во временной папке, указанной в выводе.

Чистые контрактные функции дополнительно проверяются из корня:

```sh
node --test tests/*.cjs
python -m unittest discover -s tests
```

Сборка создаёт `admin/ui/admin-ui.js` и `.css`, они хранятся в Git. Python Dockerfile
копирует каталог `admin`; Node на сервере не нужен. После изменения сборки обновите
версии ресурсов в `admin/index.html`. Для публикации потребуется обычное обновление
и пересборка контейнера на сервере.
