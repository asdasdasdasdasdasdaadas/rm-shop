# Панель управления

React + shadcn/ui (New York / Radix), Tailwind CSS 4, Vite. Компоненты Button,
Dialog, Command и Tooltip взяты из официального реестра shadcn/ui; Command адаптирован
для русского заголовка и доступного описания. Дизайн использует нейтральную палитру Zinc.

## Сборка

```sh
cd admin-ui
npm ci
npm run check
npm run build
npm test
```

Сборка обновляет `admin/ui/admin-ui.js` и `admin/ui/admin-ui.css`. Эти файлы хранятся
в Git: текущий Python Dockerfile уже копирует каталог `admin`, Node на сервере не нужен.
После изменения сборки обновите версии ресурсов в `admin/index.html`.

Браузерная проверка требует установленный Google Chrome. Она использует моковые API,
проверяет 13 разделов, поиск, диалоги, темы и мобильную таблицу без отправки сообщений
и изменения реальных данных. Скриншоты сохраняются во временную папку.

## Границы компонентов

React управляет навигацией, командным поиском, подтверждениями и toast-сообщениями.
`admin/app.js` сохраняет существующие API-контроллеры, значения форм и содержимое таблиц.
React не рендерит повторно узлы, которыми владеют эти контроллеры. Событие `admin:navigate`
синхронизирует активный пункт меню. Старое меню и подтверждения остаются резервным
вариантом при недоступности JS-модуля.

`src/theme.css` собирает прежние правила раскладки в CSS-слой `legacy`, затем применяет
единую тему ко всем экранам. Tailwind utilities имеют приоритет для компонентов shadcn.
