Превью сообщения

Автобэкап

Дамп PostgreSQL каждый день в 00:01 по Москве. Файлы на сервере, скачать можно здесь.

Импорт при переезде

Загрузите .sql или .sql.gz. Текущая база будет полностью заменена. .env не меняется.

Файл Размер Создан

Меняется сразу, без правки .env. Токены, панель и база здесь не показываются.
