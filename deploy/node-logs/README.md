# Логи нод для диагностики «подключился, но трафика нет»

Сборщик `ship.py` стоит на каждой VPN-ноде. Раз в минуту он спрашивает у бота, за какими устройствами
следить: новые за 72 часа, те, по кому пришло «нет трафика», и отмеченные в админке «Следить 24 ч».
По ним он пересылает строки логов Xray. Всё остальное остаётся на ноде, поэтому трафик и база не растут.
В боте строки хранятся 72 часа и превращаются в вывод в уведомлении «Подключился, но трафика нет» и на
вкладке «Устройства» в карточке клиента.

## 1. Бот

В `.env` бота задайте секрет и перезапустите бота:

```
NODE_LOGS_TOKEN=длинная-случайная-строка
```

Пока `NODE_LOGS_TOKEN` пустой, приём логов выключен.

## 2. Логи Xray на ноде

В панели Remnawave → Config Profiles → в профиле, который стоит на нодах, задайте блок `log`:

```json
"log": {
  "loglevel": "warning",
  "access": "/var/log/remnanode/access.log",
  "error": "/var/log/remnanode/error.log"
}
```

В `docker-compose.yml` ноды (рядом с `remnanode`) примонтируйте папку логов и перезапустите ноду:

```yaml
    volumes:
      - /var/log/remnanode:/var/log/remnanode
```

Ограничьте размер логов, чтобы они не заняли диск. Файл `/etc/logrotate.d/remnanode`:

```
/var/log/remnanode/*.log {
    size 50M
    rotate 3
    missingok
    notifempty
    copytruncate
}
```

`loglevel: "warning"` показывает обрывы и ошибки рукопожатия. Если причин окажется мало, поставьте
`"info"`: строк будет больше, но и деталей тоже.

## 3. Сборщик на ноде

Скопируйте `ship.py` в `/opt/node-logs/ship.py` и запустите рядом с нодой:

```bash
docker run -d --name node-logs --restart unless-stopped \
  -v /var/log/remnanode:/var/log/remnanode:ro \
  -v /opt/node-logs/ship.py:/ship.py:ro \
  -e BOT_URL=https://адрес-бота \
  -e NODE_LOGS_TOKEN=тот-же-секрет \
  -e NODE_NAME=Германия-1 \
  python:3.12-alpine python -u /ship.py
```

`BOT_URL` — тот же публичный адрес, на который приходят вебхуки оплаты (`/webhooks/cispay`).
Проверка: `docker logs node-logs` — пусто, значит всё хорошо; ошибки отправки печатаются туда.

## Что означает вывод

| Вывод | Что происходит |
|---|---|
| До ноды не дошло ни одного соединения | провайдер не пускает к IP или порту сервера, или приложение не подключилось |
| Нода не принимает ключ | устройство выключено, ключ устарел, приложение взяло старую подписку |
| Рукопожатие не проходит | соединение доходит, но провайдер режет протокол (DPI) |
| Соединения открываются и сразу рвутся | блокировка после рукопожатия |
| Через ноду идут запросы к сайтам | VPN работает, статистика трафика просто отстаёт |
