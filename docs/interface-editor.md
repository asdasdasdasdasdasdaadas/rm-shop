# Редактор веб-приложения

Раздел админки: **Управление → Интерфейс вебаппа** (`/admin/#interface`).

## Работа с редактором

1. Выберите экран. Вкладка «Тексты и кнопки» меняет доступные заголовки, описания и подписи стандартных кнопок. Пустое поле возвращает стандартный текст.
2. Во вкладке «Блоки» на главной можно переставлять и скрывать карточки устройств, приглашений, промокода и амбассадорства. Устройства скрыть нельзя. Включение условной карточки не отменяет условий её доступности.
3. На 11 экранах можно добавлять свои текстовые блоки, карточки и кнопки. Они располагаются после основного содержимого экрана; их порядок меняется стрелками. Для кнопки выбирается существующее действие или HTTPS-ссылка.
4. «Оформление» меняет общие цвета фона, карточек, текста и основных кнопок, а также скругление карточек.
5. Предпросмотр использует HTML, CSS и общий renderer веб-приложения с демонстрационными данными. Платёжные и пользовательские API в нём не вызываются. Он не заменяет проверку всех состояний конкретного пользователя.
6. «Сохранить черновик» не меняет сайт. «Опубликовать» сохраняет текущие изменения и применяет их после следующей загрузки кабинета. «Откат» возвращает предыдущую публикацию, включая стандартный интерфейс после первой публикации.

Баланс, цены, сроки подарка, статусы подключения, формы оплаты и логика доступа не редактируются здесь. Контент FAQ и новости по-прежнему редактируются в своих разделах.

## Хранение и проверка

`webapp_interface` содержит черновик, опубликованную и предыдущую версии. Проверка номера ревизии предотвращает перезапись изменений из другой вкладки. При конфликте нужно перезагрузить редактор и повторить изменения.

Каталог разрешённых полей и действий — `webapp/ui-catalog.json`. Сервер не принимает произвольный HTML, CSS или JavaScript как настройки; тексты отображаются через `textContent`. Системные поля нельзя подменить произвольным селектором.

После обновления кода требуется пересборка и перезапуск контейнера bot: при старте применяется схема БД. Файлы собранной админки включены в репозиторий. Само обновление не публикует новый дизайн и не меняет существующие пользовательские настройки.
