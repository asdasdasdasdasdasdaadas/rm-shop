# Приглашение без регистрации

Ветка в редакторе воронки: «Приглашение без регистрации».

Первое наблюдаемое действие `invite`, `share` или `copy` в боте/веб-кабинете сохраняет `users.invite_opened_at`. Это интерес к приглашению, а не подтверждение отправки другу. URL-кнопки Telegram сами по себе не присылают callback.

Через 72 часа отправляется одно сообщение с личной ссылкой и готовым текстом через Telegram Share. Старше 14 дней интерес не обрабатывается. Повторные нажатия не сбрасывают таймер. Если после первого интереса человек нажал «Пока не нужен», новое действие с приглашением после этого отказа начинает новый отсчёт. Уже отправленный шаг повторно не отправляется. Наличие любого пользователя с `referred_by` останавливает сценарий. Учитываются общие ограничения воронки: блокировки, тихий режим, пауза, поддержка, бюджет сообщений; дополнительно исключены маркетинговые сообщения за последние 48 часов.

Существующие ветки подключения/первой оплаты работают для зарегистрировавшихся друзей. Уведомления о начисленных реферальных бонусах остаются в существующем механизме начисления.

Миграция сохраняет резервную копию графа в `app_flags.referral_followup_v1_backup` и один раз добавляет ветку, не меняя остальные шаги. Если все 32 места заняты, существующие ветки продолжают работать: миграция откладывается без отметки о завершении и повторяется при следующей загрузке после освобождения места. Совпадения идентификаторов с пользовательскими ветками разрешаются добавлением суффикса. После установки отключение/редактирование ветки администратором сохраняется. При миграции сообщения не отправляются. Старые нажатия не восстанавливаются из суточной статистики: там нет точного времени события.
