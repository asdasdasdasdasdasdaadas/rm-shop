# Основной дизайн кабинета

Новый тёмный интерфейс — единственный дизайн для всех пользователей и администраторов. Атрибуты оформления заданы в HTML до загрузки стилей; `appearance.js` закрепляет их независимо от старых настроек браузера, темы Telegram и прежней A/B-группы.

Переключатели дизайна и цветов удалены. A/B-назначение, сбор событий, серверные обработчики и вкладка админки удалены. Существующие таблицы с историей эксперимента не удаляются из рабочей базы; новая установка их не создаёт. Историю реализации можно найти в Git.

Общие `app.css` и скрытые элементы, которые использует логика кабинета, сохранены как основа интерфейса. Вернуться к старому дизайну через настройки или API нельзя. `WayAppearance.choose` и `assign` оставлены как совместимые безопасные вызовы: они не включают старое оформление.

Проверки: `node --test tests/*.cjs`, `node admin-ui/tests/appearance.cjs`, `node admin-ui/tests/beta-screens.cjs`, `node admin-ui/tests/beta-motion.cjs`, `node admin-ui/tests/smoke.cjs`. Браузерные сценарии используют тестовые API, без реальных платежей и сообщений.
