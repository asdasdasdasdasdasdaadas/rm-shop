# Рост: как привести больше людей

**Статус: идеи на потом.** Здесь только описание и дизайн. В коде бота и кабинета этого пока нет.
Макеты: [mockups.html](mockups.html). Откройте их через любой локальный сервер из корня репозитория,
например `python3 -m http.server 8000`, затем перейдите на `http://localhost:8000/docs/growth/mockups.html`.
Страница берёт стили и Lottie-подарок прямо из `webapp/`.

Что уже есть: рефералка (другу 50 ₽ сразу, вам 50 ₽, когда друг подключит VPN), «Подарить другу»
(в том числе «Подарки в группу» на несколько человек), рекламные ссылки для партнёров со статистикой,
напоминания пригласить друга в воронке.

## 1. Подарок в чат через inline: оформление на выбор (сделано)

Даритель выбирает одно из четырёх оформлений. Оно действует везде: в карточке во вкладке «Подарить»,
в карточке в Telegram и на экране, где друг открывает подарок.

| Оформление | `style` | Подарок | Фон |
|---|---|---|---|
| Фиолетовый | `violet` (по умолчанию) | белый, золотая лента | фиолетовый с лучами |
| Праздничный | `festive` | красный, золотая лента | изумрудный, конфетти |
| Золотой | `gold` | золотой, чёрная лента | почти чёрный, золотое конфетти |
| Закатный | `sunset` | мятный, белая лента | розово-оранжевый |

**В кабинете** (`webapp/cab.js`: `GSTY`, `gStyBlock`, `gCard`, `gPick`)
- Под карточкой с суммой есть раздел «Оформление» с четырьмя плитками, в каждой живой мини-подарок.
  При выборе фон плавно сменяется, а подарок пружинисто появляется в новых цветах.
- Ниже «Так увидит друг» (или «Так увидит чат» при ×N) — превью карточки в Telegram с текстом и кнопкой.
- Количество задаётся как раньше: «Своя», затем тап по подарку на клавиатуре (×N), долгое нажатие сбрасывает.
  Подарок на клавиатуре тоже в выбранном оформлении.
- Цвета подарка получаются перекраской Wallet Lottie (`fbWalk` с палитрой оформления).
- Экран друга (`SCR.present`) берёт `style` из `GET /api/gifts/{code}`.

**На сервере**
- Колонка `friend_gifts.style` (`TEXT`, по умолчанию `violet`). Незнакомое значение превращается в `violet` (`clean_style`).
- `POST /api/gifts` принимает `style`. Его отдают `/api/gifts`, `/api/gifts/{code}` и ответ создания подарка.
- `prepare_share` отправляет анимированную карточку `InlineQueryResultMpeg4Gif`: беззвучное MP4 1200×630,
  примерно 3 секунды по кругу, около 630 КБ (лимит Telegram 1 МБ).
  - Если MP4 нет, уходит JPG того же оформления (`InlineQueryResultPhoto`).
  - Если нет и его, уходит старая `gift-card.jpg`.
- Файлы лежат в `webapp/icons/gift-cards/{style}-{one|chat}.{mp4,jpg}`: «one» — другу, «chat» — три подарка
  для группы. На карточке нет числа ×N, потому что картинки заранее готовые. Количество есть в подписи.
- Превью ссылки `/g/CODE` (`og:image`) тоже в оформлении подарка.

**Как перерисовать карточки.** Нужно сделать скриншоты карточки в Chrome (кадр за кадром для MP4).
Карточка в той же вёрстке, что превью в кабинете (`.gs-art`), растянута до 1200×630. Цикл бесшовный:
подарок проигрывается дважды (94 кадра Lottie при 60 fps), лучи поворачиваются на одну полосу (20°),
каждое конфетти падает целое число раз. Затем 94 кадра при 30 fps кодируются в H.264.

## 2. Награда за оплату друга

Сейчас приглашающий получает 50 ₽, когда друг подключит VPN. **Новое:** ещё 20% от первой оплаты друга.
Так приглашающему есть смысл довести друга до оплаты. Накрутить нельзя: награда платится только с
реальных денег.

- **«Пригласить» в кабинете.** Фиолетовая карточка с бело-золотым подарком, крупно «50 ₽ + 20%»,
  шаги «Как это работает».
- **«Ваши друзья».** Для каждого друга видно, на каком он шаге (открыл бота → подключил → оплатил)
  и сколько он принёс.
- **Баннер на главной.** «+20% с первой оплаты каждого друга», подарок наполовину за краем, как у «+35%».
- **Сообщения в боте.** «Петя подключил VPN — вам +50 ₽» и «Аня оплатила VPN — вам +60 ₽», с кнопкой «Пригласить ещё».

Правила:
- 20% начисляются только с первой оплаты друга. Разумно поставить потолок, например 200 ₽ за одного друга.
- Если платёж вернули, награда списывается (`referral_revoke` уже есть).
- Процент и потолок вынести в настройки, рядом с `referral_reward_rub`.

## 3. Подарочный VPN на Новый год

Строится на готовом «Подарить другу», выпустить нужно до начала декабря.

- **Вкладка «Подарить».** Синий подарок на снегу, суммы 300 / 500 / 1000 ₽ с подписью в днях VPN.
  Выбор открытки («Ёлка», «Дед Мороз», «Мандарины») и поле для поздравления.
- **Открытка в Telegram.** Подарок, сумма, поздравление и кнопка «Открыть подарок».
- **Друг открывает подарок.** Крышка слетает, вылетают искры, сумма считается вверх, видно, от кого
  подарок и поздравление.
- **Рассылка 15 декабря.** «Подарите близким VPN на праздники», кнопка ведёт сразу на новогоднюю вкладку.

Что добавить в код: у подарка поля «открытка» и «поздравление» (до 200 символов, без ссылок),
картинка-открытка на каждый дизайн, новогоднее оформление вкладки на время праздников.

## 4. Остальные идеи

- **Приглашение на экране «Оплата прошла».** Человек в этот момент доволен: «Поделитесь с другом —
  ему 50 ₽, вам 50 ₽». Сейчас приглашение приходит только через 2 дня после подключения.
- **Награда за нескольких друзей.** «3 подключившихся друга → +150 ₽ сверху»: даёт цель позвать ещё.
- **Обязательная подписка на канал.** Посмотреть, сколько людей отваливается между /start и проверкой
  канала. Если больше 10–15%, убрать проверку или перенести её позже.
- **Оформление бота в BotFather.** Короткое описание, описание и превью кабинета, чтобы чаще жали
  «Старт» из поиска и пересланных ссылок. Это делается без кода.
- **Цена платящего по рекламным ссылкам.** Для каждой ссылки считать расход ÷ число оплативших,
  чтобы переносить бюджет в каналы, которые окупаются.
